# PranavWebDesign portfolio

Single-page static portfolio. Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Deploy

Any static host works. On Cloudflare Pages: framework preset "None", build command empty, output directory `/`.

## Notes

- `preview.png` is the og:image for social share cards. Keep it in the repo root.
- Live projects referenced: [discountdeals4u.ca](https://discountdeals4u.ca) (client store) and [maplemart.store](https://maplemart.store) (demo build, QAGuru test environment).
